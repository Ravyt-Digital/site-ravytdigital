# Mensuração da Ravyt Digital

| Ação | Evento Meta |
| --- | --- |
| Página carregada | PageView |
| Clique em solicitar orçamento | QuoteClick |
| Seleção da primeira estrutura do site | EstimateStart |
| Resumo do orçamento exibido | EstimateComplete |
| Orçamento copiado | EstimateCopy |
| Clique para abrir o WhatsApp | Contact |
| Formulário de orçamento aceito pela API | Lead |

Os eventos opcionais dependem do consentimento. A rota de analytics registra evento, caminho e horário. Os parâmetros dispensam dados pessoais, respostas do simulador e conteúdo de mensagens. O clique no WhatsApp indica intenção de contato. A equipe confirma o atendimento após receber a mensagem.
